# 🔮 ABARTILI RUH OKUMA MAKİNESİ 🔮

## Dünyanın En Ciddi, En Bilimsel, En Gereksiz Projesi

Hoş geldiniz, ölümlü ruhlar. Bu depo, insanlık tarihinin en büyük bilimsel başarısıdır. Ruh okuma teknolojisi artık elinizin altında. NASA, CERN ve Türk Kahvesi Falının birleşimi.

### Özellikler

- **Gerçek ruh okuma**: Kaynak: güven bana kardeşim.
- **Drama garantisi**: Her okuma sonunda en az 3 gözyaşı.
- **Sonsuz döngü**: İsterseniz tüm ömrünüzü burada geçirin.
- **Türkçe desteği**: Evet, Türkçe. Çünkü ruhlar da Türkçe konuşur.

### Kurulum

```bash
git clone https://github.com/Tentivory/abartili-ruh-okuma-makinesi.git
cd abartili-ruh-okuma-makinesi
python3 ruh_okuma.py
```

### Kullanım

İsminizi girin. Ruhunuz okunsun. Sonra pişman olun. Tekrar deneyin.

### Uyarı

Bu yazılım **gerçekten** ruh okur. Kullanımdan sonra ruhunuzun kaybolmasından sorumlu değiliz. Yasal sorumluluk reddi: Hiçbir şey. Çünkü bu bir şaka.
